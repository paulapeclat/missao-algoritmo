# Missão Algoritmo

> Aulas interativas de algoritmos, do jogo de adivinhar até a troca de um bot de regras por uma IA. Tudo roda no navegador, sem instalar nada.

**Autora:** [Paula Peclat](https://github.com/paulapeclat) · [Educação Tecnológica Paula Peclat](https://paulapeclat.com.br)

Cada missão é uma página com cinco etapas. A estudante joga, observa, testa no laboratório e termina planejando uma parte do próprio projeto. As missões se encadeiam, e cada uma retoma o que a anterior construiu.

## As missões

| Página | O que a estudante faz |
|---|---|
| [Missão 1](https://paulapeclat.github.io/missao-algoritmo/) | Divide um projeto em partes, descobre as variáveis, escreve um algoritmo com sequência, condição, eventos e repetição e transforma esse algoritmo numa mensagem clara para a IA |
| [Missão 2](https://paulapeclat.github.io/missao-algoritmo/parte-2/) | Compara busca linear e busca binária no jogo de adivinhar, usa metades e potências de 2 para provar o máximo de tentativas e reconhece algoritmos de um sistema operacional |
| [Missão 3](https://paulapeclat.github.io/missao-algoritmo/parte-3/) | Descobre como um bot de atendimento decide a resposta, ensina intenções e palavras-chave ao bot e encontra os limites das regras |
| [Missão 4](https://paulapeclat.github.io/missao-algoritmo/parte-4/) | Compara o bot de regras com um modelo de linguagem, transforma as regras em instruções para a IA e aprende a proteger a chave, os visitantes e o custo |
| [A matemática escondida no jogo de adivinhar](https://paulapeclat.github.io/missao-algoritmo/matematica-escondida/) | Texto de apoio para educadoras, educadores e famílias sobre o que a Missão 2 ensina |

## Como usar

Abra os links acima ou, sem internet, baixe o repositório e abra o `index.html` de cada pasta no navegador. O progresso fica salvo só no navegador de quem usa a página, e nada do que a estudante escreve é enviado para servidor. As fontes das páginas são carregadas do Google Fonts.
