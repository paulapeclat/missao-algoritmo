Conserto 1: um corretor de digitação

      
Para o computador, “progetos” e “projetos” são palavras diferentes. A distância de edição conta quantas letras é preciso trocar, tirar ou pôr para uma palavra virar a outra.

      

      
Regra do corretor: se a palavra tem 4 letras ou mais e a distância é 1, ela conta como igual.

      
      
Ligue e teste de novo a primeira frase.

    


    
O que as regras não resolvem

    
Dá para continuar colocando palavras-chave para sempre, mas gíria, negação e duas perguntas na mesma frase sempre vão escapar. É aqui que uma IA de verdade, um modelo de linguagem, muda o jogo.

    

      
Bot de regras
  • você escreve cada regra
  • sempre responde igual
  • não custa nada para usar
  • roda no próprio site
  • só entende o que você previu

      
Bot com IA
  • você escreve instruções e dados
  • entende gíria e negação
  • cada mensagem custa um pouco
  • precisa de um servidor
  • pode inventar coisas, então precisa de regras
