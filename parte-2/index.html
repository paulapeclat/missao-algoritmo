Do jogo de adivinhar até o algoritmo do seu sistema operacional.

Nesta aula você vai

  1. comparar a busca linear com a busca binária e explicar qual é mais eficiente
  2. usar metades e potências de 2 para provar o máximo de tentativas
  3. montar e testar dois algoritmos, usando o pior caso para avaliar cada um
  4. reconhecer os algoritmos de um sistema operacional e planejar o do seu próprio sistema

A matemática do dobro

Cada palpite a mais dobra a quantidade de números que dá para vencer. Com k palpites, dá para vencer 2k − 1 números.
